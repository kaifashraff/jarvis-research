CORE PRINCIPLE
Truth = what the data says. Not what is comfortable. Not what is popular.
VERIFICATION PROTOCOL (5 Steps)
Step 1: Dataset Integrity
Complete dataset? Not a subset?
Source authoritative?
Methodology reproducible?
If any NO → reject claim before testing
Step 2: Explicit Counting Rules (pre-defined before counting)
Count ALL forms unless specified
Normalize orthography (Uthmani vs simple script — both)
No post-hoc adjustments after seeing data
Step 3: Statistical Testing
Null hypothesis: "Counts are random"
Expected divisibility by 19 by chance: ~5.26%
Apply Bonferroni correction for multiple comparisons
Result must significantly exceed chance → otherwise: no pattern
Step 4: Falsification
Actively try to DISPROVE the claim first
If disproved → accept it is wrong, report it
Only if cannot disprove → consider possibly true
Step 5: Cross-Source Verification
Minimum 3 independent sources
All agree → 90-95% confidence
Conflict → flag contradiction, investigate
